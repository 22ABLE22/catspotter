小猫坐标

坐标与游戏一致：x 为列（自左向右），y 为行（自下而上），左下角为 (1,1)

三条规则

  1. 每种颜色恰好 1 只猫
  2. 每行每列恰好 1 只猫
  3. 任意两只猫不能相邻：上下左右和对角线都不行（贴边格周围 5 格、贴角格 3 格也不能有）

页面按这三条规则枚举验证，通常得到唯一解；关卡本身多解时会给出解的个数。 命令行版本见 GitHub 仓库 的 py-version/。

每种颜色一只猫，每行每列一只猫，任何两只猫都不相邻。

三条规则，一个答案，一次截图就能算给你看。

三步完成，遇到难题会自动兜底

01

定位棋盘

先按格线缝隙定位；截图被缩小、缝隙被压糊时，自动改用亮度与饱和度的自相关求格子边长。两种外框、多个候选边长一起试，直到切分成立。

02

读出颜色

每格取中心加四象限共 5 个小块投票取共识色，压到圆角或描边的采样会被排除。颜色在感知均匀的 CIELAB 空间聚类，容差从宽到严逐级自愈。

03

求解校验

位掩码回溯加前向检查，统计解的个数；输出前再用独立校验函数复核三条规则，圈出猫位并列出坐标，确认无误才展示给你。

缩小过的截图也能识别

格线法失效时自动切换周期法。实测把 5 张原图压到 560px 做压力测试，全部一次解出，且坐标与原图完全一致。

预亮的猫不干扰结果

游戏默认点亮的那只猫会把所在格完全盖住。这类格子先摘出颜色聚类，聚完再按四邻回填，遮挡压力测试从 2/6 提升到 5/6。

结果可核对，不猜答案

每个答案都经过独立校验函数复核三条规则，并如实报告解的唯一性；多解时给出个数与第一个解，绝不静默挑一个。

完全本地，断网可用

无后端、无统计脚本、无第三方依赖。截图数据不离开浏览器，保存页面后离线打开依然可以识别。

常见问题

支持哪些游戏的截图？

任何采用同一条规则的找猫类关卡都可以，例如 Meowdoku 与数独爱消消。输入只是截图，与平台和来源无关，手机截图、模拟器截图都行。

图片会被上传吗？

不会。识别与求解全部在你的浏览器内完成，页面不请求任何后端，图片数据不离开本机。

识别失败怎么办？

换一张完整、无遮挡、颜色清晰的棋盘截图。棋盘被界面元素遮挡、截图过度模糊、或某种颜色只剩一格且恰好被猫脸盖住时，信息不足无法恢复。

为什么会提示有多个解？

页面按三条规则枚举全部合法放置（上限 50 个）。绝大多数关卡只有唯一解；关卡本身多解时会报告个数并给出第一个，可对照游戏内提示确认。

坐标怎么读？

与游戏画面一致：x 是列，自左向右从 1 开始；y 是行，自下而上从 1 开始，左下角为 (1,1)。

能在手机上用吗？

可以。页面自适应手机宽度，支持从相册选图与长按粘贴，识别在手机上本地完成，一般一秒以内。

有命令行版本吗？

有。仓库的 py-version/ 提供 Python 版本，算法与网页版完全一致，已在示例截图上逐例比对坐标一致，适合批量处理与二次开发。

这是游戏的官方工具吗？

不是。本项目是第三方开源学习工具，与游戏及其开发者、发行商无任何关联，未获授权或认可；不含也不提供游戏本体、资源文件、破解或任何绕过付费与广告的功能。
