坐标与游戏一致：x = 列（自左向右），y = 行（自下而上），左下角为 (1,1)

规则与说明

  1. 每种颜色恰好 1 只猫
  2. 每行每列恰好 1 只猫
  3. 任意两只猫不能相邻 —— 上下左右和对角线都不行（贴边 5 格、贴角 3 格也不能有）

页面按上面三条规则枚举验证，通常得到唯一解；若关卡本身有多解，会同时给出解的个数。 识别失败时请换一张完整、无遮挡、颜色清晰的棋盘截图。 命令行版本见 GitHub 仓库 的 py-version/。
